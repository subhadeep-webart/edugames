A Trivia-SmackDown Set is assembled by a Game Master, and he/she may designate the amount of Points for each of the Rounds in order to balance the Set. This is done by a Point Factor [Game type B and D] or a starting amount [Game Type I] The default amount is 100 Points, or whatever Point factor is needed to achieve a perfect score = 100 Points.

There are three types of Games in Trivia SmackDown scored as follows:

Game B

Game type B involves players bidding to see how much of the challenge they can get correct. If they succeed in getting all correct in the allotted time, they get a Point Award that is the square of the number correct, times the Point Factor displayed at the top of the screen, plus a Time Bonus, if they beat the clock.

The Point Award for the number of items chosen is displayed at the top of the screen plus a Time Bonus for finishing before the allotted time.

However, if the player does not beat the clock, or gets even one incorrect, the opposing player gets the displayed Point Award.

Game D

Game type D requires the players to respond to the challenge with a number, date or location on a map. The Point Award is the ratio of how much closer the closets player is to the correct answer than the other player times the Displayed Point Award.

Tie scores split the Point Award.

Game I

Game I involves a Point Award, usually starting at 100 Points, that is decreasing as more information is presented.

If correctly answered

The Point award is what was displayed when the answer was selected.

If incorrectly answered

The apposing player get the Point Award and the play continues.
