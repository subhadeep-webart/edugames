Trivia-SmackDown: Basic Terms

[Return to Game]

Rounds

A Round is the basic challenge such as picking items from a list or placing items in order. The Point Award of a Round is usually 100, but is up to the discression of the Game Master.

Sets

A Set is a collection of Rounds assembled by a Game Master and is what is played.

Game Master

A Game Master assembles Rounds into Sets, usually around a specific subject. Anyone may apply to be a Game Master at the Trivia-SmackDown website [URL here]. The Application to create Sets is written in Java and can be downloaded.

Round Authors

Rounds are created using a Java Application on a user's computer and uploaded to the Trivia-SmackDown website. Anyone may apply to be a Round Author at the Trivia-SmackDown website [URL here].
